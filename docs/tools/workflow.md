# workflow

> 开发工作流工具。dev_loop: 执行 GDScript+可选验证/bridge 截图查询/验收断言/状态保存。scene_snapshot: 场景树快照。batch_validate: 批量脚本验证。create_files: 批量建文件(自动验证 .gd)。run_verify: 批量 headless 验证。diff_scenes: 场景差异。

| 属性 | 值 |

| 所属层 | headless |
| 安全级别 | guarded |
| 需要 Godot | 是 |
| 需要编辑器 | 否 |
| 只读 | 否 |
| 长耗时 | 是 |

## Parameters

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `action` | enum (6 项) | ✓ | 操作类型。dev_loop=执行+验证一体, scene_snapshot=场景树快照, batch_validate=批量脚本验证, create_files=批量创建文件, run_verify=批量验证场景, diff_scenes=场景差异比较 |
| `project_path` | string |  | 项目目录（默认 GODOT_PROJECT_PATH 或当前目录） |
| `code` | string |  | dev_loop: 要执行的 GDScript 代码(片段或完整 extends SceneTree) |
| `verify` | boolean |  | dev_loop: 执行后是否跑项目验证(默认 false) |
| `timeout` | number |  | dev_loop: 每步超时秒数(默认 30) |
| `load_autoloads` | boolean |  | dev_loop: 是否加载 Autoload 上下文(默认 true) |
| `bridge` | object |  | dev_loop: 可选 Game Bridge,代码执行后截图/查询验证 |
| `acceptance` | object |  | dev_loop: 可选验收标准 |
| `save_state` | object |  | dev_loop: 保存会话状态到文件 |
| `scene_path` | string |  | scene_snapshot: 场景文件路径(相对项目) |
| `max_depth` | number |  | scene_snapshot: 最大遍历深度(默认 5) |
| `scripts` | array |  | batch_validate: 脚本路径数组(相对项目) |
| `files` | array |  | create_files: Array of files to create |
| `validate` | boolean |  | create_files: Validate .gd files after creation (default: true) |
| `scenes` | array |  | run_verify: Array of scene paths relative to project |
| `capture_tree` | boolean |  | run_verify: Capture scene tree snapshot (default: false) |
| `scene_a` | string |  | diff_scenes: First scene path relative to project |
| `scene_b` | string |  | diff_scenes: Second scene path relative to project |
| `ignore_properties` | array |  | diff_scenes: Property names to ignore in diff (default: metadata/_edit_lock) |
| `godot_path` | string |  | Godot 路径覆盖（可选，优先于配置/env） |
