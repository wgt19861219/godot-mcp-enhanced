# runtime

> 启动编辑器、运行/停止项目、取调试输出、跑测试、查 Godot 版本、录制回放。run_project: timeout 0/-1=不自动停(手动 stop_project), wait_for_bridge=轮询等 bridge 就绪, preview=窗口常驻, profiling=绑调试端口。需 GODOT_PATH(或项目级 .godot/mcp-godot.json)。详见 help 工具。

| 属性 | 值 |
|------|-----|
| 所属层 | bridge |
| 安全级别 | danger-api |
| 需要 Godot | 是 |
| 需要编辑器 | 否 |
| 只读 | 否 |
| 长耗时 | 是 |

## Parameters

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `action` | enum (11 项) | ✓ | 操作类型。launch_editor=开编辑器, run_project/stop_project=运行/停止游戏, get_debug_output=取调试输出, run_tests=跑测试, get_godot_version=查版本, record_*=录制回放(start/stop/save/load/play) |
| `project_path` | string |  | 项目目录（默认 GODOT_PROJECT_PATH 或当前目录）。多项目并行按项目分桶(同项目重跑互杀,跨项目并存);stop_project/get_debug_output 缺省操作最近 run 的项目,传本参数可指定其他会话桶 |
| `timeout` | number |  | run_project: 自动停止秒数(默认 30;0/-1=不自动停,由 stop_project 手动控——bridge 逐步交互会话推荐 0,冷启动>30s 的项目传更大值如 120;wait_for_bridge 时正数自动取 max(bridge_timeout+10, timeout) 防 race)。run_tests: 单次 GUT 进程超时秒数(默认 120,分片时 per-shard 计时) |
| `wait_for_bridge` | boolean |  | true 时 spawn 后轮询 bridge 就绪(默认 false,向后兼容) |
| `profiling` | boolean |  | true 时 spawn 前绑 debugger 端口并传 --remote-debug(函数级 profiling 前置,之后用 profiler capture_functions 采样;仅 spawn 模式,attach/已运行会话无 debugger 通道) |
| `bridge_timeout` | number |  | wait_for_bridge 轮询总预算(秒,默认 10) |
| `preview` | boolean |  | 预览模式:禁用自动停止,游戏窗口常驻,用户关窗即结束(AI 改完代码/场景后的人工视觉验证);默认不与 wait_for_bridge 组合(bridge 未就绪会终止游戏,见规则) |
| `test_script` | string |  | 测试脚本或目录路径（默认 res://test/） |
| `quit_flag` | enum: gquit | gexit |  | run_tests 的 GUT 退出标志。默认 gquit(GUT ≤9.5);GUT 9.6+ 移除 -gquit(报 Unknown arguments: -gquit)时切 gexit |
| `shards` | integer |  | run_tests 分片数(默认 1=单进程现有行为)。>1 时:TS 侧枚举 test_script 目录下 *.gd(递归,排除 addons/ 段与 _ 前缀),蛇形均衡分 N 片,逐片生成临时 gutconfig 经 -gconfig= 显式覆盖项目 .gutconfig.json(防 dirs 附加合并),串行执行,失败/超时片不中断,汇总各片 Tests/Failed。大测试集防单进程 OOM(2026-11-12 反馈:单进程全量跑 22.5GB 死机)。GODOT_TEST_MODE env 透传到子进程(调用方 shell 设了才传) |
| `events_json` | string |  | 录制：JSON 格式的事件序列字符串 |
| `file_name` | string |  | 录制保存:始终自动命名 recording_YYYYMMDD_HHmmss.json(file_name 入参被忽略);但 file_name 须匹配 recording_*.json 格式(否则 INVALID_FILE_NAME),禁止含 / \\ .. |
| `speed` | number |  | 录制：回放速度倍率（默认 1.0） |
| `load_autoloads` | boolean |  | 加载 Autoload（默认 true） |
| `godot_path` | string |  | Godot 路径覆盖（可选，优先于配置/env） |
