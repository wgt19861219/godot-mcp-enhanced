# uid

> 文件 UID 管理(Godot 4.4+)。scan: 扫描缺 .uid 资源与孤儿 .uid。get: 查文件 UID(批量)。set: 写 .uid(指定 uid/generate 单文件/fix_missing 批量修复)。check_refs: 检测 uid:// 悬空引用(仅对照项目 .uid 集合;uid 悬空但 ext_resource 另有 path fallback 的引用引擎可正常加载,计入 dangling 属诊断提示,非断链)。运行时操作，仅影响当前执行上下文。如需持久化，请编辑 .tscn 文件。

## Parameters

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `action` | enum (4 项) | ✓ | 操作类型。uid_scan=扫描项目 UID, uid_get=批量查 UID, uid_set=设 UID, uid_check_refs=检查 UID 引用 |
| `project_path` | string |  | Godot 项目目录路径（可选，默认使用 GODOT_PROJECT_PATH 环境变量或当前目录） |
| `paths` | array |  | get: 文件路径列表(res:// 相对,支持批量) |
| `path` | string |  | set: 单文件路径(res:// 相对) |
| `uid` | string |  | set: 指定 UID 文本(uid://xxxx);省略则按路径确定性生成(与编辑器一致) |
| `fix_missing` | boolean |  | set: 批量修复全部缺 .uid 的资源 |
| `extensions` | array |  | scan/set 参与的资源扩展(小写,默认 26 个常见类型) |
| `limit` | number |  | scan/check_refs 明细截断上限(默认 100,最大 500) |
