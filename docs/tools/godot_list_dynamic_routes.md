# godot_list_dynamic_routes

> 三级 lazy discovery:查询可用工具(静态注册 + 动态发现)。无参返回 category 计数;search 模糊匹配;category 查某类工具清单;tool 查单工具完整 schema。

| 属性 | 值 |
|------|-----|
| 所属层 | headless |
| 安全级别 | safe |
| 需要 Godot | 是 |
| 需要编辑器 | 否 |
| 只读 | 是 |
| 长耗时 | 否 |

## Parameters

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `category` | string |  | 类别名 → 返回该类工具清单(brief + 参数名,lean 视图)。配合 includeSchemas=true 可一次性返回完整 schema。 |
| `search` | string |  | 关键词(空格分隔),全部命中才匹配;名字命中排名优先。上限 20 条,不带 schema。 |
| `tool` | string |  | 工具名 → 返回单工具完整 schema(优先级最高,覆盖 search/category)。 |
| `includeSchemas` | boolean |  | 配合 category 使用:一次性返回该类所有工具的完整 schema(体积大,慎用)。 |
