# manage_tools

> 动态管理工具组的启用/停用状态。始终可用，不可被禁用。支持 list_groups（列出所有组+profile 价格标签）、discover（关键词发现工具——全量 45 工具×action 搜索评分,返回匹配/所属组/激活态/激活指引,未激活组里的能力由此发现）、activate（启用组）、deactivate（停用组）、sync（同步连接状态）、reconnect（手动重连）。
