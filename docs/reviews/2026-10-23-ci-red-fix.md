## 工程教训(值得跨会话保留)

1. **vitest workspace→projects 迁移会静默失效一批 CLI flag**:`test.projects` 化后 CLI `--exclude` 不透传 project 文件收集;迁移 checklist 应逐个核对 CLI override 透传性,不能假设 flag 语义随 config 结构升级自动延续。
2. **headless Godot 无 vsync 不限帧,"N 帧 ≈ X 秒"的 wall 假设在快机不可靠**:fixture 级 `_ready` 设 `Engine.max_fps = 60` 是通用稳定器;安全论证必须按"frames_budget 上限 × wall 预算"推演,不能按想当然的机制描述。
3. **CI 门禁依赖 registry 已发布版本的安装形态,两次 publish 之间必然红**:CI smoke 验证对象应是当前 commit(本地 pack + 宿主 build + COPY),分发验证(生产 Dockerfile/Glama)与 CI 门禁解耦是可复用分层范式。
