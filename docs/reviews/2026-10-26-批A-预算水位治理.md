## 值得进 memory 的工程教训

1. **「实测数字」必须以最终产物为准复取**:同一提交内脚本注释/CHANGELOG/最终 matrix 三处快照漂移,根因是数字写于最后一次 matrix 重建前——快照护栏适用于代码注释与 CHANGELOG 中的「实测」声明。
2. **WHATWG file URL 盘符 quirk**:`file://D:/path` 在 Windows Node.js 有效(盘符归入 path 而非 host);按「必须三斜杠」通用规则报错会是误报,仓内 check-tool-groups.mjs 是先例。
3. **plan 验收数字与落地不一致时,「校准门线」应显式对照偏差记录**,保持 spec→实现→验证链可追溯。
