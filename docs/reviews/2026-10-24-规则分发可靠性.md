## 值得进 memory 的工程教训

1. "分发版本行读磁盘 + 模板内容 import 进内存"是模板分发系统的通用毒化根因——两源年龄可分离时必写出"新版本号+旧内容",且按版本行判新旧的机制会永久背书错误状态。单一固化源 + 入口拦截的修复成本远低于事后指纹检测。
2. 新增"只读巡检"函数最容易绕开既有安全防线——write 路径有确认门、read 路径有白名单的仓库里,新加只读 IO 面常被默认豁免校验。安全自查应按"本批新增的每一处文件系统访问"逐点核,而非按功能核。
