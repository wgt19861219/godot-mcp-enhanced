## 值得进 memory 的工程教训

1. **TS 侧 `current === null` 区分不了 GD 属性缺失与 null 值**——GD `node.get()` 两态同返 null,`"prop" in node` 才是权威判定;同一 bridge 内 step_until(用)与 wait_for_property(未用)已现不同步。
2. **声明 outputSchema 的工具,catch 降级路径也要给 structuredContent**——双通道承诺是工具级的,不是 happy-path 级的。
3. **多 action 聚合工具(如 game)无法对单 action 如实声明工具级 outputSchema**——输出侧 structuredContent 可先行、schema 声明留给单形态工具。
4. **预算阈值注释的 KB 必须写明十进制/二进制口径**——`116 * 1024` 配 "~800B 余量" 的十进制算术会让后续校准者误判余量。
