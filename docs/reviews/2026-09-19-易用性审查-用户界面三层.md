# 2026-09-19 代码易用性审查：用户界面的可理解性 / 可学习性 / 可操作性

> **审查性质**：独立易用性审查（非 plan 落地审查）。三个并行子代理分维度审查 + 主审逐项实测核验，只读不改代码。
> **"用户界面"界定**：本项目是 MCP server，使用者分两类——**AI（MCP 客户端里的模型）看到的工具接口**、**人类看到的 CLI 与监控面板**；学习路径载体是**文档体系**。三层分别对应可理解性/可操作性/可学习性的主战场。
> **核验声明**：本文所有计数类数字均由主审用命令实测（方法见文末「验证命令索引」），非转述子代理声明。

## 总体判定

**SHIPPED WITH NITS（易用性专项）/ 中上水平、骨架优秀但表层一致性欠账明显。**

三层界面的**基础设施质量高**：结构化错误体系（error_code/suggestion/retryable）、help 工具 46/46 文档全覆盖、CLI 的幂等/备份/原子写/退出码惯例、README 中 CLI 命令 100% 真实有效。但**"接缝处"打磨不均**：工具接口是几十次增量开发累积出的措辞漂移（英文残留、参数描述 16 种变体、action 命名三种语序）；CLI 两端（首跑引导、完成后的下一步）断头；文档的核心资产（46 个工具文档、27KB 主使用指南）是 README 零链接的孤岛。对存量用户影响有限，对**新接入的 AI 客户端和新手人类用户**，首次成功成本被明显抬高。

问题统计：**MAJOR 16 项 / MINOR 若干 / NIT 若干**（明细见各维度表；终审 `grep -c "| MAJOR"` 实测 16 行，修正本报告初版头部的「MAJOR 12 项」计数错误——闭环账目见终审报告 `2026-09-19-易用性修复终审.md`：完全闭环 13 + 替代方案 1 + 部分闭环 1 + defer 1）。

## 优点汇总（审查平衡性）

1. **错误信息体系**是同类 MCP server 上乘水准：结构化信封 + 头部错误的「下一步」指引（A-9）。
2. **help 工具**：46/46 文档全覆盖 + 拼写纠错 + 46 工具名动态 enum——基础设施完整，缺的只是引流（A-6）。
3. **CLI 中段工程质量**：幂等跳过、损坏配置先备份、原子写、env 白名单键保留、退出码惯例明示（B-5/B-6/B-9）。
4. **防漂移机制**：SUBCOMMANDS 单一真相源、changelog-sync CI、版本表与 package.json 一致（C-5）。
5. **README 命令零失效**——快速上手路径里的命令全部真实可跑（C-5）。
6. schema 工程质量：required/default 零矛盾（全量扫描实测）、截断防护、持久化警示自动注入（A-11）。
