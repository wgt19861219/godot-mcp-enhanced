## 一、背景与根因（实证链）

### 1.1 实测故障复现（2026-10-24，godot-mcp-enhanced 自身验收）

- 环境状态：磁盘 build 已更新至 0.36.1（build/index.js mtime 10:58:22），但 ZCode 会话连的 godot server 进程启动于 10:58 之前（内存模板 = 0.36.0 旧版）。
- 操作：对 `D:\workspace\projects\godot-test-project` 跑 `setup_project_rules(update)`。
- 结果：落盘 10 个规则文件**头部版本行写 0.36.1+，内容是 0.36.0 旧模板**（实证：落盘 ui.md 23,790 字符无 A1 段「跨引擎迁移 UI 构建策略」；本仓库 `.claude/rules/godot-mcp-ui.md` 30,006 字符 A1 段在 line 19）。
- 毒化机制：下次**新进程**跑 update，reconcile 按 manifest 版本行判定"目标已是 0.36.1"→ 跳过更新——错误状态被版本行永久背书，只能 overwrite 强制修复（还击穿"保留用户动过的文件"保护）。

### 1.2 代码根因（两源不一致）

| 源 | 位置 | 时机 | 值 |
|---|---|---|---|
| 分发版本行 | `src/tools/project.ts:480-481` `readFileSync(mcpPkgPath)` 运行时读 | 每次分发 | 磁盘当前值（总是最新） |
| 模板内容 | `GODOT_MCP_RULES` / `DETAILED_RULE_TEMPLATES`（import 进内存） | 进程启动 | 跟随进程年龄（可旧） |

同一进程内两源可不一致 → "新版本号 + 旧内容"文件。**正确形态已存在于仓库**：`src/core/update-checker.ts:11-12` 与 `src/tools/self-update.ts:16-18` 的 `createRequire(import.meta.url)` + `require('../../package.json').version` 是**模块加载时固化**（与模板同源同岁），但 `project.ts` 未复用它。

### 1.3 用户暴露面（为什么是产品缺陷而非开发环境问题）

普通 npm 用户 `npm update` 后：①客户端不重启 → 进程旧（MCP 生态通病）；②不知道要重跑 `setup_project_rules`（使用指南 FAQ 只写了①没写②）；③在旧进程上跑分发 → 毒化（零报错）；④之后重启客户端再跑 update → reconcile 判"已是新版"跳过 → **静默永久停留旧规则**。防线盘点：`self_update(check)` 只查 npm 最新版+addon 漂移不查规则状态（且其 expected 用进程固化值，旧进程上反向误报）；`doctor` 无规则分发检查项；`godot_get_context` 响应无 serverVersion/startedAt（用户侧无法判定进程新旧）。

### 1.4 现成基础设施（削减工程量的关键发现）

`src/tools/rules-manifest.ts:10-15` 的 `RuleManifestEntry` **已有内容 hash 字段**（CRLF 归一化后 `sha256:<hex>`，安装时写入）。毒化根因是 reconcile 判定**以版本行为主键、hash 仅用于判用户改动**——指纹能力在而未用于 server 侧内容一致性判定。

## 二、目标与非目标

### 目标

1. **G1 拦截**：两源不一致时拒绝分发，把静默陷阱变成显式报错（消"毒化"+"分发旧内容"两道坑）。
2. **G2 可见化**：server 进程身份可查（version/startedAt/pid）；`self_update(check)` 与 `doctor` 能报告规则分发状态（含毒化检测）。
3. **G3 批量**：CLI `rules` 子命令一次分发全部白名单项目（CLI 每次新起进程，天然免疫毒化）。
4. **G4 文档**：升级指引补齐"两步走"（重启客户端 → 重跑分发），写进 README 主体而非只藏 FAQ。

### 非目标

- **不做** C2 工具侧强制挂载（长期方案，维持 deferred，见 UI 迁移方案 deferred 项）。
- **不做** MCP resources 自动注入规则（客户端不自动加载 resources，无护栏价值，见上一轮分析）。
- **不 bump 版本**：本批不动 `rule-templates.ts` / `.claude/rules/`（模板内容零变更），`check-rules-version-bump.mjs` 不触发；变更进 CHANGELOG `[Unreleased]`（AGENTS.md「默认不发版」定规）。

### P1-2 reconcile 增加内容指纹维度（毒化检测）

`src/tools/rules-manifest.ts` + `src/tools/project.ts:483-540` reconcile 段：

- `FileClassification` 增加第五类 `'content-drift'`（版本行相同 + manifest hash ≠ 当前进程模板渲染 hash + 用户未动过）。

- `content-drift` + 用户动过 → 等价 stale-and-modified 保留并警告（用户改动优先）。
- hash 计算复用现有 CRLF 归一化函数（manifest 写入时已在用，找到该函数复用）。

### P1-3 self_update(check) 扩展规则状态
